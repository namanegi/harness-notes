实验笔记

关于决策、计划与模型协作的研究，从单次调用到完整 agent 系统。

Jev：从一次选择走到任务结束

同样的选择接口，背后可能是很不同的能力要求。这个系列先探查边界，再比较替代方案，最后测完整系统。

  1. 决策模型，究竟能替 agent 做哪些判断？——单体动作探针、推理失败与候选分数。
  2. Jev 与 Luna：先把判断比公平，再算费用——匹配状态、指令封装、缓存与条件转交。
  3. 便宜的决策，能组成便宜的 agent 吗？——参数生成、工具拒绝、复核与停止。
