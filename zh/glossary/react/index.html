术语表

ReAct

将推理与行动交替进行，并利用环境返回的观察来决定下一步。

Agent 可以先判断缺少什么证据，再调用工具，根据返回结果调整下一步。本站 Jev 系列用“ReAct 式”描述这种依据反馈逐步行动的方式。替换循环中的一个决策点，并不等于替换工具执行与停止逻辑。
