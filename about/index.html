关于 Harness Notes

我是 namanegi。这里记录我对 Harness Engineering 的兴趣：怎样把模型、工具、状态和反馈组合成能完成任务的系统。

我用小规模实验检验具体设想，也保留失败、实现错误和结论的限制。文章是研究笔记，不是生产可靠性承诺。

每项研究的结果回到其独立方法和数据。已发表文章保留日期；影响结论的更正在原文注明。博客页面与编辑历史可在 GitHub 检查。
