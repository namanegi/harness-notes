Jev: from a choice to a finished task

The same choice interface can hide very different demands. This series first maps the capability, then compares alternatives, then measures the complete system.

  1. What can a decision model actually decide? — standalone action probes, reasoning failures and candidate scores.
  2. Jev vs. Luna: compare the decision, then count the cost — matched states, instruction packaging, caching and conditional handoff.
  3. Can cheap decisions make a cheap agent? — parameter generation, rejected tools, verification and stopping.
