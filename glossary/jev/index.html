Glossary

Jev

TypeSafe's structured decision model, used here to select options, score relevance and make yes/no judgments.

In these experiments the surrounding program supplies context, defines the available decisions and executes tools. Jev supplies a decision within that setup. A correct local choice does not establish that the complete agent can finish a task. Model versions and measured costs belong to each experiment, rather than this general definition.
