Glossary

Noul

A TypeSafe yes/no question type that returns a probability for yes. A threshold turns the value into a filtering decision.

The reranking experiment asks whether a chunk contains useful evidence. A value below the chosen threshold removes the chunk in the filtering condition. The threshold changes the tradeoff between retaining noise and losing evidence; the returned value alone does not establish calibration on this dataset.
