Glossary

Recall · Recall@k

The fraction of known relevant documents that retrieval finds. Recall@10 counts relevant documents in the first ten results.

If a query has five known relevant documents and the first ten results include two, Recall@10 is 2/5 = 0.4. Reordering the same ten documents cannot change this value. The denominator depends on the evaluation collection and its relevance labels; it does not represent all useful information on the web.
