Glossary

ReAct

An approach that interleaves reasoning with actions, using observations from the environment to inform the next step.

An agent can reason about missing evidence, call a tool and then update its next action from the returned observation. The Jev series uses 'ReAct-style' for this feedback-driven pattern. Replacing one decision within the loop does not replace the surrounding tool execution or stopping logic.
