Glossary

Concepts, interfaces and metrics used in the experiments. Start with a short explanation, then follow a term back to the research.

  • Jev

    TypeSafe's structured decision model, used here to select options, score relevance and make yes/no judgments.

  • Jev Choice

    A TypeSafe question type that selects one option from a defined set, with weights for the candidate options.

  • Jev Score

    A TypeSafe question type that rates content against ordered descriptions. Its score is an expectation over level numbers, not a relevance percentage.

  • Noul

    A TypeSafe yes/no question type that returns a probability for yes. A threshold turns the value into a filtering decision.

  • RAG · Retrieval-augmented generation

    Retrieve relevant material and provide it to a model as context for generating an answer.

  • Reranking

    Reorder an already retrieved candidate set using another relevance judgment, so useful evidence appears earlier.

  • Embedding

    A numerical vector representation of content. Retrieval can compare query and document vectors to find likely relevant material.

  • Chunk

    A piece of a document treated as one retrieval unit. Its boundaries affect which evidence arrives together.

  • nDCG · Normalized discounted cumulative gain

    A ranking metric that rewards putting more relevant results earlier. The @10 suffix evaluates the first ten positions.

  • Precision · P@k

    How much of the returned material is relevant. In this site's P@10 metric, the denominator stays ten even if fewer results are returned.

  • Recall · Recall@k

    The fraction of known relevant documents that retrieval finds. Recall@10 counts relevant documents in the first ten results.

  • Top-1 · First-result relevance

    In the reranking study, the fraction of queries whose first result is labeled relevant.

  • ReAct

    An approach that interleaves reasoning with actions, using observations from the environment to inform the next step.
