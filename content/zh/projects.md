# 实验笔记

关于决策、计划与模型协作的研究，从单次调用到完整 agent 系统。

## Jev：从一次选择走到任务结束

同样的选择接口，背后可能是很不同的能力要求。这个系列先探查边界，再比较替代方案，最后测完整系统。

1. [决策模型，究竟能替 agent 做哪些判断？](@/projects/jev-choices/)——单体动作探针、推理失败与候选分数。
2. [Jev 与 Luna：先把判断比公平，再算费用](@/projects/jev-comparison/)——匹配状态、指令封装、缓存与条件转交。
3. [便宜的决策，能组成便宜的 agent 吗？](@/projects/jev/)——参数生成、工具拒绝、复核与停止。

[系列共用的方法与结果附录](@/research/jev-report/)

## 先排好计划，真的会更快吗？

固定依赖图可以暴露并行机会。在 40 道检索和竞赛题上，这没有变成稳定的加速。完成率和延迟分布说明了只看正确率会遗漏什么。

[阅读 Compile, Then Act? →](@/projects/compile-then-act/)

## 小模型一起讨论，谁来核对答案？

正确答案有时在讨论前已经出现，讨论后却消失。专门的检查员有改善迹象，也会继承同样的错误。沿着轮次、任务和人数的变化，看看答案如何被改写。
